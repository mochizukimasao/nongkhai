Nongkhai Editor

基本操作

  • 新規ノート: サイドバー上部の「＋」ボタン
  • ノート切替: サイドバーから選択（モバイルは選択で閉じる）
  • お気に入り/ゴミ箱: ★・ゴミ箱トグルで切替
  • 履歴: ノート行の時計アイコンから復元/参照
  • テーマ・フォント・文字数: ツールバー右側で切替
  • 効果音/BGM: スピーカー/傘アイコンでON/OFF

ショートカット

キー動作
Ctrl/Cmd + L箇条書きトグル（行頭に「- 」を付与）
Cmd + Shift + H見出しトグル（行の # レベルを循環）
Ctrl/Cmd + A全選択
Enter（リスト/引用行）箇条書き・番号リスト・引用の継続/解除
Ctrl/Cmd + Z取り消し
Ctrl/Cmd + Shift + Z / Ctrl/Cmd + Yやり直し
Ctrl/Cmd + C / Vコピー / ペースト

独自ホットキーは上記のみです。他はブラウザ標準を利用します。

Tips

  • 入力は自動保存（最長4秒以内）。離脱時も保留保存をフラッシュ。
  • 文字数カウントは右下トグルで表示。
  • 背景画像・BGM・設定は次回起動時に復元。
  • モバイルは左上の三本線でサイドバーを開閉。

データと同期

  • ローカル: IndexedDB に保存。オフライン編集可。
  • クラウド: Firebase ログインで Firestore とミラー同期。
  • ゴミ箱: 30日で自動削除。ゴミ箱表示から復元可。
