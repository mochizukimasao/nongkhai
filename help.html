Nongkhai 操作マニュアル

このページはサイドバー下部の「操作マニュアル / Info」からいつでも開けます。

メコン川の壮大さと静けさをイメージした、余白のあるミニマルな筆記空間。音・背景・光を静かに調律し、ローカル保存の安心とワンタップ同期の身軽さで、思考を邪魔せず書くことだけに没頭できるメモ空間。

基本操作

  • 新規ノート: サイドバー上部の「＋」ボタン。
  • ノート切替: サイドバーのリストから選択。モバイルは選択すると自動で閉じます。
  • お気に入り/ゴミ箱: サイドバー上部の★・ゴミ箱トグルで絞り込み。
  • 履歴: ノート行の時計アイコンから復元/参照。
  • テーマ・フォント・文字数: ツールバー右側の各ボタンで切替。
  • 効果音/BGM: スピーカー/傘アイコンでON/OFF。音が不要ならOFFのままでOK。
Shortcuts

ショートカット一覧（現在設定されているもの）

キー動作
Ctrl/Cmd + L箇条書きトグル（行頭に「- 」を付与）
Cmd + Shift + H見出しトグル（行の # レベルを循環）
Ctrl/Cmd + A全選択（エディタ内でフォーカス維持）
Enter（リスト/引用行）箇条書き・番号リスト・引用の継続/解除を自動入力
Ctrl/Cmd + Z取り消し（ブラウザ標準、ツールバーのUndoでも可）
Ctrl/Cmd + Shift + Z または Ctrl/Cmd + Yやり直し（ブラウザ標準、ツールバーのRedoでも可）
Ctrl/Cmd + C / Vコピー / ペースト（ブラウザ標準、ツールバーのCopy/Pasteボタンでも可）

現時点では独自のホットキーは上記のみです。その他はブラウザ標準のキー操作がそのまま使えます。

Tips

  • 入力は自動保存（短い間隔＋最大4秒で保存）。ページ離脱時も保留中の保存を flush します。
  • 文字数カウントをオンにすると右下にリアルタイム表示されます。
  • 背景画像・BGMは設定に保存され、次回起動時に復元されます。
  • モバイルではフローティングメニュー（左上の三本線）からサイドバーを開閉します。

データと同期

  • ローカル: IndexedDB に保存。オフラインでも編集可能です。
  • クラウド同期: Firebase にログインすると Firestore と双方向同期します（上書きミラー）。
  • ゴミ箱: 30日経過で自動削除。復元はゴミ箱表示から可能です。
